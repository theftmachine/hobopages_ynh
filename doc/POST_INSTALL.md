HoboPages is ready at https://__DOMAIN__

Sign in with the admin password you chose during installation, add a site, then drag your built folder into the drop bay. The site appears at `https://__DOMAIN__/<site-name>/`.

Two notes:

- This app takes over the whole domain. Site names become paths on it, so don't install anything else here.
- Keep the app's permission set to **visitors**. The published sites need to be reachable by anyone; the admin interface is protected by its own password regardless.
